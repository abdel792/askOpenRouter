# Спросить OpenRouter

* Автор(ы) : Abdel.

Это дополнение NVDA позволяет вам взаимодействовать с моделями искусственного интеллекта, предоставляемыми платформой OpenRouter, непосредственно из программы чтения с экрана.

Дополнение поддерживает оба:
* Автоматический случайный выбор бесплатных моделей
* Ручной выбор любой доступной модели (в том числе платной)

## Ключевые возможности

* Быстрый доступ: открывайте интерфейс чата в любое время с помощью глобальной комбинации клавиш.
* Управление беседой: начните новую беседу или продолжите предыдущую.
* Интеллектуальная прокручивание бесплатных моделей: автоматически выбирает случайную бесплатную модель для оптимизации ежедневных квот использования.
* Выбор модели вручную: выберите конкретную модель (включая платные модели) на панели настроек.
* Доступные результаты: просматривайте ответы в чётком, удобном для навигации окне с дополнительным отображением полной истории.

## Конфигурация: получение и установка API-ключа

Чтобы использовать это дополнение, вам необходимо иметь API-ключ OpenRouter.

Даже при использовании бесплатных моделей ключ требуется для идентификации ваших запросов.

### 1. Как получить API-ключ

1. Перейдите на сайт [OpenRouter.ai](https://openrouter.ai/).
2. Создайте учётную запись, нажав "Sign up" (вы можете войти с помощью учётной записи GitHub, Google или MetaMask, либо по адресу электронной почты).
3. После входа в систему перейдите в раздел "Keys" на панели управления или перейдите непосредственно по адресу: https://openrouter.ai/keys
4. Нажмите кнопку "Create Key".
5. Задайте своему ключу имя (например: "My OpenRouter API key") и щёлкните "Create".
6. Важно: ваш ключ отобразится только один раз. Немедленно скопируйте его и сохраните в надёжном месте.

### 2. Настройка ключа в NVDA

1. Откройте меню NVDA (NVDA + N).
2. Перейдите в Параметры, затем Настройки.
3. В списке категорий выберите "Спросить OpenRouter".
4. Вставьте ваш API-ключ в поле "API-ключ OpenRouter".
5. Нажмите OK для сохранения.

#### Показать API-ключ

На панели настроек NVDA, сразу после поля "API-ключ OpenRouter", есть флажок:

"Показывать API-ключ"

Если он отмечен, символы API-ключа становятся видимыми.
По умолчанию они скрыты из соображений безопасности.

## Настройки выбора модели

В категории настроек Спросить OpenRouter вы найдёте новый параметр:

### "Использовать все модели, включая платные"

Этот параметр управляет способом выбора моделей.

### Когда параметр не отмечен (поведение по умолчанию)

* Дополнение автоматически выбирает случайную бесплатную модель для каждой новой беседы.
* Оно прокручивает между доступными бесплатными моделями.
* Это помогает распределить использование и избежать ограничений скорости.

### Когда параметр отмечен

Если этот параметр включён, после флажка автоматически появится список доступных моделей.

* Список отсортирован по возрастанию на основе цены жетона запроса (стоимость входного жетона), от самой низкой к самой высокой.
* Отображаются только неустаревшие модели с действительными поставщиками.

### Что можно делать, когда этот параметр включён?

* Выбирать любую доступную модель.
* Использовать платные модели (если у вас достаточно кредитов OpenRouter).
* Выбирать модель, которая лучше всего соответствует вашим потребностям.
* Продолжать использовать ту же выбранную модель для своих бесед (без автоматического кругового переключения).

### Что такое жетон запроса?

Жетон запроса представляет собой небольшой блок текста, отправленный в модель (ваш вопрос или входные данные).

Модели обычно оплачиваются отдельно за:
* Входные жетоны (запрос)
* Выходные жетоны (ответ)

## Как Использовать

### Открытие Диалога Чата

Нажмите:

Ctrl + Alt + A

Вы можете изменить этот жест в:
Меню NVDA → Параметры → Жесты ввода → Спросить OpenRouter

### Главный Интерфейс

Диалог содержит три кнопки:

1. Новый чат – начинает совершенно новую беседу.
2. Продолжить чат – возобновляет предыдущую беседу (сохраняет историю).
3. Закрыть – закрывает диалог (также работает клавиша Escape).

### Ввод приглашения

После выбора "Новый чат" или "Продолжить чат":

* Появляется многострочное текстовое поле.
* Нажатие Enter вставляет новую строку.
* Чтобы отправить ваше сообщение:
  - Нажмите Tab, чтобы перейти к кнопке ОК.
  - Нажмите Enter.

### Чтение ответа

После обработки появляется окно с результатами, содержащее:

* "Вы сказали:" с последующим вашим сообщением.
* "Модель ответила:" с последующим ответом.
* Кнопка "Копировать" для копирования ответа.

Если включено полное отображение истории, каждый обмен чётко разделён заголовками, что упрощает перемещение с помощью клавиш быстрой навигации NVDA.

## Параметры отображения

Если вы предпочитаете отображать только последний ответ вместо полной истории беседы:

1. Откройте меню NVDA (NVDA + N).
2. Перейдите в Параметры → Настройки.
3. Выберите Спросить OpenRouter.
4. Снимите флажок:
   "Отображать полную историю чата для продолжающихся обсуждений"
5. Нажмите OK.

## Неназначенные скрипты

Следующие скрипты не имеют назначенных жестов.
Вы можете определить их в:

Параметры → Жесты ввода → Спросить OpenRouter

Доступные скрипты:

* Открыть панель настроек дополнения
* Начать новый чат напрямую
* Продолжить существующий чат напрямую

## Бесплатные Модели, Платные Модели и Квоты

### Использование Бесплатных Моделей

Когда не отмечено "Использовать все модели, включая платные":

* Используются только модели, помеченные как бесплатные на OpenRouter.
* Бесплатные модели имеют:
  - Ограниченные ежедневные квоты
  - Общие ограничения на количество запросов
  - Возможную временную недоступность

Дополнение автоматически переключается между бесплатными моделями для улучшения доступности.

### Использование Платных Моделей

Когда отмечено "Использовать все модели, включая платные":

* Дополнение использует именно ту модель, которую вы выбрали.
* Сюда могут входить платные модели.
* У вас должно быть достаточно кредитов OpenRouter.
* Могут применяться ограничения тарифов поставщика.

Такие ошибки, как:
* 402 (недостаточно кредитов)
* 429 (превышен лимит)
* 404 (модель не разрешена настройками конфиденциальности)

отображаются непосредственно для информирования вас о проблеме.

## Напоминание о настройках конфиденциальности

Если вы используете бесплатные модели и получаете сообщение об ошибке:

> "No endpoints found matching your data policy"

Возможно, вам придётся изменить настройки конфиденциальности OpenRouter:

https://openrouter.ai/settings/privacy

Убедитесь, что разрешены публичные/бесплатные конечные точки моделей.
